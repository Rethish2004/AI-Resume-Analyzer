# AI Resume Analyzer

An AI Resume Analyzer web application that analyzes resumes against job descriptions and helps job seekers improve their resumes.

## Features

- Upload a resume for analysis
- Detect resume skills
- Calculate resume match and ATS scores
- Identify matched and missing skills
- Provide resume improvement suggestions
- View previous analysis history
- Download the analysis report as a PDF
- User registration and login

## Technologies Used

- **Frontend:** React.js, JavaScript, HTML, CSS
- **Backend:** Python, Flask
- **Database:** SQLite
- **Analysis:** Resume keyword and skill matching
- **Deployment:** Render
- **Version Control:** Git and GitHub
